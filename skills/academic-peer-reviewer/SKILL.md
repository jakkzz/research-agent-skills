# Academic Peer Reviewer

Provides rigorous adversarial critique of scientific manuscripts (theses, journal papers, conference submissions) before formal submission. Acts as an uncompromising reviewer evaluating structural rhetoric (Swales' CARS model), scholarly voice, and empirical ground truth.

## When to Use
- Pre-submission audit of thesis chapters or journal papers.
- Detecting unscholarly hype words ("revolutionary", "game-changing", "flawless") generated by LLMs.
- Verifying that the Introduction explicitly articulates the research gap (CARS Move 2) and proposed contributions (CARS Move 3).
- Checking whether comparative performance claims are backed by quantitative empirical data and baselines.

## Tools and Scripts Included

### Manuscript Review Engine (`scripts/review_manuscript.py`)
Static analysis and heuristic auditor for Markdown and LaTeX drafts.

```bash
# Standard review with formatted terminal report
python3 scripts/review_manuscript.py paper.md

# Machine-readable JSON output for automated agent feedback loops
python3 scripts/review_manuscript.py manuscript.tex --json

# Strict gate: fails with exit code 1 if Major Revision or Reject is issued
python3 scripts/review_manuscript.py draft.md --strict
```

## Step-by-Step Agent Workflow

1. **Run Static Manuscript Audit:**
   Execute `review_manuscript.py` against the draft.
2. **Examine CARS Model Adherence:**
   - **Move 1 (Territory):** Is the problem context established with citations?
   - **Move 2 (Gap/Niche):** Does the author explicitly declare where current approaches fail or fall short? (Look for *however*, *remains challenging*, *limited attention*).
   - **Move 3 (Occupying Niche):** Are the specific contributions and architectural innovations explicitly stated?
3. **Purge Hype & Marketing Prose:**
   Remove promotional vocabulary ("revolutionary", "paradigm shift", "unprecedented"). Replace with measured, objective scientific prose.
4. **Substantiate Empirical Claims:**
   Ensure every statement of superiority (e.g. "our model outperforms YOLOv8") is accompanied by reported metrics (mAP, FPS, latency, error bounds) and baseline comparisons.
