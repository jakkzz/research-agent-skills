# Changelog

All notable changes are documented here. The project is alpha; interfaces and output schemas may change before a stable release.

## Unreleased

### Changed

- Marked project maturity and runtime compatibility claims as alpha/Pending without committed live-runtime evidence.
- Made copy installation safe by default with explicit agent/scope selection, atomic staging and rollback, ownership manifests, drift-aware uninstall, dry-run, and opt-in force/symlink behavior.
- Reframed manuscript review as deterministic lexical/structural preflight without publication verdicts.
- Tightened citation input handling, duplicate-key reporting, and `\\nocite{*}` behavior.
- Added explicit source status and partial-failure reporting to arXiv/Crossref candidate discovery.
- Added DOCX XML-character validation, visible fallback for unmatched inline Markdown, heading styles, overwrite protection, and atomic writes.

### Added

- Linux, macOS, and Windows CI for unit tests, compilation, CLI help, diff checks, and tracked-artifact hygiene.
- Security policy and truthful maturity/claims ADR.
